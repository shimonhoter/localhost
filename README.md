# localhost

אפליקציית Android שמקבלת קובץ HTML (דרך "פתיחה באמצעות", שיתוף, או בחירה ידנית מהאפליקציה עצמה),
מפעילה עבורו שרת HTTP מקומי (`127.0.0.1`, פורט פנוי אוטומטי) ומציגה אותו ב-WebView תחת
`http://127.0.0.1:<port>/...`.

ברגע שהמסך/העמוד נסגר (`onDestroy`), השרת המקומי נסגר מיידית והפורט משתחרר.

## מבנה

- `LocalHttpServer.kt` — שרת סטטי מינימלי מבוסס `ServerSocket`, מאזין רק על `127.0.0.1`
  (לא נגיש מרשת חיצונית), משרת קבצים מתיקייה נתונה.
- `MainActivity.kt` — מטפל ב-`ACTION_VIEW`/`ACTION_SEND`/בחירה ידנית, מפעיל את השרת,
  טוען את הדף ב-WebView, וסוגר הכל ב-`onDestroy`.

## קבצים מקומיים (`file://`)

נטענים ישירות מהתיקייה המקורית שלהם — כך שקבצי `css`/`js`/תמונות יחסיים ממשיכים לעבוד.

## קבצים משותפים (`content://`)

מועתקים פעם אחת לתיקיית cache ייעודית של האפליקציה (כי השרת המקומי יכול לשרת רק קבצים
שיושבים בפועל על הדיסק), ונמחקים בסגירה.

## בנייה

הבנייה מתבצעת ב-GitHub Actions (ראו `.github/workflows/build.yml`) — כל push ל-`main`
מייצר APK debug כ-artifact.
